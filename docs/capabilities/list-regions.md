# Яндекс Вордстат: Справочное дерево регионов — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Вордстата:** Возвращает справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label).

Техническое имя: `list_regions`

## Какую задачу решает

> Я хочу получить справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label).

Возвращает справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label).

## Когда использовать

Используйте эту возможность, когда нужен результат «Справочное дерево регионов» без ручной работы в интерфейсе Яндекс Вордстата. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label).

## Что изменится в Яндекс Вордстате

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label) в Яндекс Вордстате. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Эти id подставляются в regionIds/regionMode остальных инструментов, а названия расшифровывают id регионов в их ответах. Дерево большое и стабильное: достаточно запросить его один раз и закешировать.

Доступ также зависит от прав токена, квот и ограничений исходного API.
