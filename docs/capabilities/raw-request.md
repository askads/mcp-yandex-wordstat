# Яндекс Вордстат: Прямой вызов API Вордстата — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Вордстата:** Универсальный запрос: обращается напрямую к любому пути Wordstat в Yandex Cloud Search API — для эндпоинтов, у которых нет отдельного инструмента, например "v2/wordstat/topRequests".

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Универсальный запрос: обращается напрямую к любому пути Wordstat в Yandex Cloud Search API — для эндпоинтов, у которых нет отдельного инструмента, например "v2/wordstat/topRequests".

## Когда использовать

Используйте эту возможность, когда нужен результат «Прямой вызов API Вордстата» без ручной работы в интерфейсе Яндекс Вордстата. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Путь API, например "v2/wordstat/dynamics".
- `method` — **необязательно**. HTTP-метод. Поддерживается только POST, он же по умолчанию.
- `body` — **необязательно**. Тело запроса в формате JSON.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Вордстате

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Выполнить дополнительный запрос к API в Яндекс Вордстате. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Все эндпоинты Вордстата работают методом POST; `body` отправляется как JSON (folderId подставляется автоматически).

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
