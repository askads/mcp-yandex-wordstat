# Яндекс Вордстат: Динамика спроса во времени — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Вордстата:** Возвращает, как менялся спрос на фразу во времени, — ряд {date, count, share}, где share — доля от всех поисковых запросов Яндекса.

Техническое имя: `dynamics`

## Какую задачу решает

> Я хочу узнать динамику поискового спроса.

Возвращает, как менялся спрос на фразу во времени, — ряд {date, count, share}, где share — доля от всех поисковых запросов Яндекса.

## Когда использовать

Используйте эту возможность, когда нужен результат «Динамика спроса во времени» без ручной работы в интерфейсе Яндекс Вордстата. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `phrase` — **обязательно**. Поисковая фраза для анализа.
- `period` — **необязательно**. Шаг ряда. По умолчанию monthly.
- `fromDate` — **необязательно**. Начало диапазона (RFC3339), например 2026-01-01T00:00:00Z.
- `toDate` — **необязательно**. Конец диапазона (RFC3339), выровненный по границе периода.
- `regionIds` — **необязательно**. Id регионов, которыми ограничить спрос, например [213] (Москва), [2] (Санкт-Петербург). Id берутся из list_regions. Без параметра — все регионы.
- `devices` — **необязательно**. Фильтр по устройствам: любые из all, desktop, phone, tablet. Без параметра — все устройства.

## Что вернёт

Возвращает, как менялся спрос на фразу во времени, — ряд {date, count, share}, где share — доля от всех поисковых запросов Яндекса.

## Что изменится в Яндекс Вордстате

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Узнать динамику поискового спроса в Яндекс Вордстате. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Подходит для оценки сезонности и тренда. period задаёт шаг ряда (daily/weekly/monthly). fromDate/toDate ограничивают диапазон метками времени RFC3339, при этом toDate должен попадать на границу периода.

Доступ также зависит от прав токена, квот и ограничений исходного API.
