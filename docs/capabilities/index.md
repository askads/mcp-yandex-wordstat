# MCP-возможности Яндекс Вордстата

Каталог содержит 5 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-yandex-wordstat`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Поисковый спрос

- [Динамика спроса во времени](./dynamics.md) — Возвращает, как менялся спрос на фразу во времени, — ряд {date, count, share}, где share — доля от всех поисковых запросов Яндекса. **Воздействие:** только чтение.
- [Справочное дерево регионов](./list-regions.md) — Возвращает справочное дерево регионов, которые поддерживает Вордстат, — id регионов и их названия (label). **Воздействие:** только чтение.
- [Распределение по регионам](./regions.md) — Возвращает, как спрос на фразу распределён по регионам за последние 30 дней. **Воздействие:** только чтение.
- [Топ и похожие запросы](./top-requests.md) — Возвращает поисковый спрос по фразе за последние 30 дней: самые популярные запросы, которые СОДЕРЖАТ фразу (results), и семантически ПОХОЖИЕ запросы, которые могут её не содержать (associations), плюс totalCount. **Воздействие:** только чтение.

## Дополнительные методы API

- [Прямой вызов API Вордстата](./raw-request.md) — Универсальный запрос: обращается напрямую к любому пути Wordstat в Yandex Cloud Search API — для эндпоинтов, у которых нет отдельного инструмента, например "v2/wordstat/topRequests". **Воздействие:** только чтение.
